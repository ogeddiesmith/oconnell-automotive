# O'Connell Automotive

Static one-page site for an independent auto repair mechanic in Kankakee, IL.

**Live:** https://ogeddiesmith.github.io/oconnell-automotive/

Built from `build.py` into `docs/`, and GitHub Pages publishes only main `/docs` (since 2026-10-10), so
`build.py`, `make-og.py` and this README are not served. `images/` and `brand/` are the sources; the build copies
them into `docs/`. Do not hand-edit anything in `docs/`, the next build overwrites it.

    python3 build.py

The site is currently `NOINDEX` while naming and photography are being finalized.
